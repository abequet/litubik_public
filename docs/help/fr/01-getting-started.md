# Bien démarrer

LitUbik accompagne une revue systématique de littérature du protocole au
diagramme PRISMA, avec plusieurs reviewers et une assistance IA optionnelle.

## Premiers pas

1. **Créez un projet** depuis la page d'accueil (*New project*). La personne
   qui le crée en devient l'**admin**. Juste après la création, une courte
   **configuration des accès** vous guide à travers les trois types d'accès
   optionnels : votre accès bibliothèque institutionnel (pour les PDF sous
   paywall), les clés API des bases (Scopus, IEEE…) et les clés IA. Chaque
   étape peut être passée et configurée plus tard dans les réglages du
   projet.
2. **Invitez vos co-reviewers** : sur la carte du projet, ouvrez *Members* et
   ajoutez-les par e-mail. S'ils n'ont pas encore de compte, l'invitation
   s'active quand ils s'inscrivent avec cette adresse.
3. **Suivez le pipeline** dans la barre latérale : Protocole → Équations →
   Recherche → Dédoublonnage → Screening → Récupération FT → Screening FT →
   Snowballing → Extraction → Résultats → PRISMA. Chaque étape se débloque
   naturellement à mesure que la précédente avance ; le numéro surligné
   indique où vous en êtes.

## Rôles

- **Superadmin de l'app** — le premier compte créé sur l'instance. Gère les
  réglages globaux (clés IA et bases de données de l'app, section
  *Administration* de la barre latérale).
- **Admin de projet** — gère les membres, réglages, clés IA et prompts d'un
  projet (bouton ⚙ sur la carte du projet ou *Settings* dans la barre
  latérale), et voit le temps de travail actif de chaque reviewer par étape
  (page *Temps de travail*).
- **Reviewer** — screene, vote, extrait les données ; voit son propre temps
  de travail dans le panneau Membres (voir *Collaboration*).

## Le tour guidé

À votre première connexion, un court tour guidé présente l'interface. Vous
pouvez le relancer à tout moment depuis le menu **?** de l'en-tête.
